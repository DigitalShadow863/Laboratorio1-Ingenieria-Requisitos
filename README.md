# Laboratorio 1 – Ingeniería de Requisitos

## Sistema de Gestión de Reservas para el Hotel GINZHA

### Descripción

Este repositorio contiene los artefactos desarrollados para el laboratorio de Ingeniería de Requisitos, utilizando un caso práctico simulado de un sistema de gestión de reservas para el Hotel GINZHA.

El sistema busca mejorar el registro y control de clientes y reservas, así como reducir problemas relacionados con reservas duplicadas y desorganización de información.

### Contenido del repositorio

* **01_Documentacion:** documentos PDF del laboratorio y SRS.
* **02_Requisitos:** catálogo de requisitos, criterios de aceptación y checklist.
* **03_Diagramas:** diagramas UML del sistema.
* **04_Modelio:** archivo fuente del modelo desarrollado en Modelio.
* **05_Trazabilidad:** matriz de trazabilidad de requisitos.
* **06_Evidencias:** capturas utilizadas como evidencia del desarrollo.

### Requisitos identificados

* RF-01 a RF-08: Requisitos funcionales.
* RNF-01 a RNF-05: Requisitos no funcionales.
